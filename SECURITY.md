# Security Policy

## Reporting a vulnerability

If you believe you found a security issue in faysk.dev, please report it privately by email:

**contato@faysk.dev**

Please include enough information to reproduce and assess the issue, such as:

- affected URL or component;
- reproduction steps;
- expected and observed behaviour;
- potential impact;
- screenshots or proof-of-concept details when useful.

Do not include credentials, secrets or unrelated personal data in a report.

## Scope

The public portfolio, its Cloudflare Pages deployment and the contact endpoint are in scope for responsible reports.

Third-party products linked from the portfolio are not automatically in scope. If an issue belongs to a third party, report it through that provider's security process.

## Disclosure

Please avoid publishing exploitable details before there has been a reasonable opportunity to investigate and remediate the issue.

This project does not currently operate a paid bug-bounty programme. Responsible security reports are still appreciated.
