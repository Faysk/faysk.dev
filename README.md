# faysk.dev

Personal developer hub for Faysk.

This repository owns the root domain experience:

```txt
https://faysk.dev
```

The goal is to keep the root site focused on identity, projects, labs and links. Larger experiments live in their own repositories and subdomains.

## Current Sites

```txt
faysk.dev      -> main hub
lab.faysk.dev  -> browser telemetry lab
```

## Local Structure

```txt
E:\Project\
  faysk.dev\   -> this hub repository
  faysk-lab\   -> browser telemetry lab repository
```

## Stack

- HTML
- CSS
- Vanilla JavaScript with ES Modules
- Cloudflare Pages

## Development

Open `index.html` directly or serve the folder with any static server.

## Deployment

Cloudflare Pages should point this repository to the root domain `faysk.dev`.
